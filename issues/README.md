# Issues

Findings from a full review of the repository, one file per issue. Each file is self-contained: current behaviour, a reproduction where one exists, and a suggested fix. Every file also carries a note that documentation and code comments written while fixing it must stand alone and not refer back to the issue.

The status column tracks whether an issue has been addressed: `open` for outstanding, ✅ for fixed.

Numbering groups issues by area: 001-019 command-line tool, 020-039 IDL translator, 040-049 compatibility and diff, 050-069 C# code generator, 070-079 build, packaging and documentation.
